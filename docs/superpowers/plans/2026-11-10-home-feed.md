# 首页：最近 48 小时热门瀑布流 实施计划

- 日期：2026-11-10
- 对应设计：`docs/superpowers/specs/2026-11-10-home-feed-design.md`
- 状态：已实现（2026-11-10，见文末「实施结果」）

## 步骤

### 1. 查询层：`helpers.query_home_feed(limit, window)`

- 放在 `helpers.py`（与 `query_cached_tag` 同类的"库内查询"，函数体内延迟 import `models`，保持叶子）。
- JST 朴素时间：`(datetime.now(timezone.utc) + timedelta(hours=9)).replace(tzinfo=None)`。
- 先按 48h 查；`window='auto'` 且不足 `limit` 时再按 168h 查一次。
- 标签条件（R18 固定 + BlockedTag）单列一组，`OperationalError` 时去掉标签条件重查并记 warning。
- 返回 `(results, window_hours)`。

### 2. 路由：`routes_home.py`

- `bp = Blueprint('home', __name__)`，仅 `GET /api/home`。
- 60 秒进程内缓存，键为 `window`（`auto` / `48`），带锁；暴露 `clear_home_cache()`。
- 参数归一：`window` 只认 `48`，其余一律 `auto`（不做 400，避免前端拼错就整页空白）。

### 3. 组装：`app.py`

- 注册 `home_bp`。
- `/` → `home.html`；新增 `/explore` → `index.html`。

### 4. 模板：`templates/home.html`

- 导航（首页 active）+ 头部 + 时间窗说明条 + `#homeGrid` + 空状态 + 页脚。
- 内联首页样式：`column-count` 瀑布流、纯图卡片、左下角信息牌、`@media (hover: none)` 常显。
- 引入 `app.js` / `lightbox.js` / `page-home.js`。

### 5. 前端：`static/page-home.js`

- `fetch('/api/home')` → 渲染卡片（`img[data-src]` 懒加载 + `lazyLoad()`）。
- 信息牌只放名称与作者，`pointer-events: none`，整张图可点。
- 点击 → `lightbox.open(首页整批, index)`。
- `window_hours > 48` 时切到降级说明条；按钮触发 `?window=48` 重取。
- 空结果 → 空状态，不再请求任何上游。

### 6. 其余模板的导航

8 个模板统一：新增「首页」指向 `/`，原「搜索」指向 `/explore`（`login.html` 无导航，跳过）。

### 7. 屏蔽标签失效

`routes_settings.py` 里屏蔽标签增删已调 `clear_search_cache()`，同处加 `clear_home_cache()`。

### 8. 测试

- 新增 `tests/test_home.py`（见设计「验证」）。
- 改 `tests/test_app.py`：两处把"搜索页"断言从 `/` 移到 `/explore`（它们测的是搜索页本身）。
- `tests/test_auth.py` 不用改：它只断言 `/` 的 200/302，首页同样满足。

### 9. 回写

- 本文件与设计文档标记"已实现 + 验证结果"。
- `AGENTS.md`：架构表加 `routes_home.py` / `home.html` / `page-home.js`；「API 行为」补一条首页口径。

## 风险

| 风险 | 处置 |
|---|---|
| 首页在库里没数据时"空白" | 空状态直说需要预取/自动关注 |
| 多列布局列优先顺序 | 设计已记录取舍；要行优先再改 Grid + JS |
| 60 秒缓存导致改收藏数后不立刻变化 | 可接受；屏蔽标签变更时主动清缓存 |
| 导航改动漏模板 | 8 个模板逐个改，测试断言 `/explore` 存在 |

## 实施结果

按步骤全部落地，与计划的差异只有两处：

1. **页大小用 `ITEMS_PER_PAGE` 而不是写死 24**（与图库同一约定，改设置后首页跟随）。
2. **首页卡片自带渲染函数，没有抽 `renderCard`**：两页卡片形态差异太大（纯图 + 悬浮信息牌 vs 徽章/标签/下载按钮），共用只会让两边都长出分支。

验证：

- `tests/test_home.py` 9 条通过；全量 **451 passed / 2 skipped / 0 failed**（19s）。
- 既有用例只改了三处断言：`test_app.py` 里两条"搜索页"断言从 `/` 移到 `/explore`，蓝图白名单加入 `home`。
- 临时实例冒烟通过（见设计文档「验证结果」）。
