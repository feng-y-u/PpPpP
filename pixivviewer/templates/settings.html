添加后后台会定时预取该标签的新作品；搜索命中该标签时直接秒回缓存结果。点击标签名删除；点标签内的 ⟳ 重置该标签的刷新状态；点 + 添加同义词（同一主题的多个 Pixiv 标签会合并成一个缓存条目，结果去重）。

X 图片抓取
总开关：保存后立即生效（同时写入 settings.json，重启后保持）；关闭时后台线程空转、不发任何 X 请求
0 = 停止抓取；X 限流很紧，建议 ≥ 3600
每标签每轮翻几页（每页约 20 条推文）
超出后按入库顺序淘汰最旧的记录（不删磁盘文件）
X 换版会失效，届时从浏览器开发者工具里复制新的 SearchTimeline queryId。两处都配置时以 instance/x_api.json 为准；修改后需重启生效
对已下载的 Pixiv 图片建立 dHash 索引，下载 X 图片时比对；未安装 Pillow 时自动不可用；修改后需重启生效
汉明距离 ≤ 该值判为同一张图；越小越严格（建议 4-8）；修改后需重启生效
—
X 没有免费搜索接口，抓取走网页内部 GraphQL：query_id 会随 X 发版漂移，坏了改 instance/x_api.json 即可，无需改代码。抓取违反 X ToS，账号可能被限流，风险自担。
