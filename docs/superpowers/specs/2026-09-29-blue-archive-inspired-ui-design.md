# Blue Archive 启发式视觉改版设计规格（阶段一）

- 日期：2026-09-29
- 状态：设计方案已获用户批准；本文待用户审阅
- 范围：仅搜索、图库、缓存三页的视觉与小幅布局调整
- 配套视觉稿：`opendesign/mockups/pixiv-ba-inspired-stage-one/index.html`

---

## 背景与目标

用户希望 Pixiv Viewer 呈现 Blue Archive（BA）启发的二次元校园轻科幻氛围。早期通用浅蓝 HUD 草稿被明确否定；最终方向以用户提供的详细文字简报为准：清透明亮、青春梦幻、蓝白为主、浅青与淡紫为辅，作品图片始终是视觉主体。

本阶段采用用户选择的「晴空留白 + 轻玻璃工具区」构图。设计输出是外观改版方案，不授权修改业务逻辑或立即实施应用改版。

## 已批准的设计决策

| 决策点 | 已确认方案 |
|---|---|
| 首批页面 | 搜索、图库、缓存；其余页面留待后续阶段单独决定 |
| 整体构图 | 晴空留白与轻玻璃工具区；不采用旧通用 HUD / 终端式方向 |
| 色彩与情绪 | 蓝白、低饱和浅青/淡紫；清透、轻盈、柔和、青春；文字保持清晰可读 |
| 环境背景 | 仅搜索页首屏可用极淡的校园/室内氛围插画；图库与缓存页不铺环境场景图 |
| 玻璃使用 | 限于导航、搜索与筛选/工具层；不把作品卡片全部做成玻璃卡片 |
| 控件形状 | 搜索类型、筛选项、排序选择、输入框与按钮使用常规圆角矩形，约 8px 圆角；不使用胶囊形 |
| 控件尺寸 | 控件可见表面约 36px 高，实际可点击区域至少 44px；降低视觉高度不得压缩 hit area |
| 图片呈现 | 作品图优先；无厚重边框、强阴影或遮挡；保留现有作品比例与裁切语义 |
| 素材限制 | 不使用 BA 官方角色或 Logo；首屏环境图仅用用户提供或明确有许可的校园/室内素材，无素材时使用抽象低对比 CSS 氛围，不热链外部图片 |
| 动效 | 轻柔淡入、轻微位移/缩放或透明度变化；无炫技、循环或强烈动效，并尊重 `prefers-reduced-motion` |
| 功能边界 | 保留现有业务功能、操作顺序与语义；允许小幅排版调整，不新增功能 |

## 视觉系统

### 色彩角色（参考 token）

下列值是正式视觉稿的起点；落地时需在真实文字尺寸与背景组合上复核对比度，必要时加深文字色，不得以牺牲可读性换取低对比氛围。

| Token | 参考值 | 用途 |
|---|---|---|
| `--sky-page` | `#F5FAFF` | 页面晴空白底 |
| `--sky-wash` | `#EDF8FF` | 页面浅天空渐层 |
| `--sky-cyan` | `#DFF3FF` | 搜索首屏浅青氛围 |
| `--sky-active` | `rgba(202,235,249,.68)` | 页签/筛选激活底色 |
| `--sky-lavender` | `#F0EFFB` | 少量淡紫环境光 |
| `--sky-accent` | `#7BBBD9` | 浅蓝强调/按钮表面 |
| `--sky-button-text` | `#1F3E55` | 浅蓝按钮上的深色前景，参考对比度 5.30:1 |
| `--sky-text` | `#315268` | 主文字与激活态文字 |
| `--sky-muted` | `#4B6678` | 次级小字参考值；对晴空页底约5.76:1、对 `#CAEBF9` 激活底的保守等值约4.83:1 |
| `--sky-line` | `rgba(153,198,220,.45)` | 控件细描边 |
| `--sky-glass` | `rgba(255,255,255,.66)` | 轻玻璃工具面 |
| `--radius-control` | `8px` | 筛选、排序、搜索控件等矩形圆角 |
| `--radius-panel` | `12–16px` | 搜索浮层与工具面板 |

色彩与渐变只表达背景空间感和状态层级，不用霓虹、高饱和蓝或大面积渐变。控件文字以足够深的蓝灰色呈现；浅色只用于表面与高光。

### 表面、边框与图片

- 导航栏与搜索/筛选工具区使用半透明白面、细浅蓝边与轻微模糊/高光；`backdrop-filter` 不可用时回退到较不透明的浅色表面。
- 作品网格以图片本身为主；保留当前数据决定的图片比例和裁切行为，不因本次设计统一改成方形或竖幅。
- 作品卡片不叠加环境底图，不加厚框或常驻强阴影；边缘与元信息保持轻量。
- 图标使用简洁线性图形或现有图标资源；不使用 emoji，不新增图标依赖。
- 字体沿用易读的系统无衬线字体栈（包含 `Noto Sans SC` 回退），不用 Inter、Roboto、Arial 等指定禁用字体。

### 控件尺寸与状态

- 所有可操作控件（包括导航项、搜索类型页签、筛选/排序、输入与按钮）的实际 hit area 至少 `44×44px`；正式稿以 `::before` 内缩表面约 `4px` 形成约 `36px` 高的可见面，触达宽高不随可见面缩小。
- 普通矩形圆角约 `8px`，边框轻薄、文字清楚。不得用 `border-radius:999px` 将筛选项、排序、页签或搜索框改回胶囊。
- Hover/active/focus 状态优先使用浅青底、文字变深或细描边变化；浅蓝按钮表面搭配深色文字，所有小字与控件文字/背景组合满足 WCAG AA（至少 `4.5:1`）；键盘焦点必须明显，不能只靠颜色区分。
- 排序、筛选与搜索类型控件保留原有标签、顺序和语义；视觉稿占位不代表新建控件或新功能。

## 三页布局

### 搜索页

1. 共用轻玻璃导航，当前页用简洁的文字/细线状态提示。
2. 首屏搜索区保持紧凑，以晴空白和柔和浅青/淡紫为主；只允许在此处放极淡的校园/室内环境氛围。搜索面板采用轻玻璃，不做占满首屏的大型宣传 hero。
3. 保留现有标签/画师/发现等搜索模式、输入、筛选、统计/排序和下载入口；不改变查询参数、筛选语义、异步搜索、分页或点击跳转行为。
4. 作品网格在搜索工具区之后尽早出现，作为页面主视觉。

### 图库页

1. 沿用共用导航和浅天空色页面底，但不铺场景插画。
2. 标题、收藏夹/排序、标签过滤、选择/批量操作、统计与作品网格保留现有语义与相对层级；只做视觉整理和小幅间距调整。
3. 不改默认排序、收藏行为、批量操作或卡片点击行为；不新增或扩展 lightbox。

### 缓存页

1. 沿用共用导航和浅天空色页面底，不铺场景插画。
2. 保留现有标签/收藏数/R-18/已下载等过滤项、排序、缓存状态、分页以及当前存在的浏览/刷新操作。
3. 不改预取状态、刷新语义、API 参数或缓存数据流；网格与图片呈现保持内容优先。

## 实现边界（供后续 implementation plan 使用）

### 允许涉及

- `templates/index.html`、`templates/gallery.html`、`templates/cache.html` 的呈现结构与 class。
- `static/style.css` 的语义 token、控件、导航、背景、边距、焦点/hover 状态与响应式样式。
- 若必须调整首页内联样式，仅限外观规则整理；不移除或改变任何业务接线。
- 纯视觉状态若确需 JS，必须保持现有 DOM 行为与请求语义不变，并单独说明理由；优先用 CSS 完成。

### 明确不做

- 不改 Flask 路由、API、Pixiv 请求、数据库模型、配置、搜索/筛选/下载/收藏/缓存业务逻辑。
- 不新增搜索页/缓存页 lightbox、批量选择或其他交互功能；不改变现有卡片导航。
- 不改图库默认排序或收藏/批量操作语义。
- 不重设计详情、下载管理、设置、登录、设置解锁等其他页面；它们留待后续阶段确认。
- 不使用 BA 官方角色或 Logo；没有明确许可的环境素材也不纳入；不加构建工具或第三方 UI 依赖。

## 响应式与可访问性

- 桌面与窄屏维持信息顺序；空间不足时筛选项换行，不横向挤压作品主体、不产生页面级横向滚动。
- 所有操作的触达面积至少 `44×44px`；可见表面较矮不代表 hit area 可缩小。
- 小字号正文与控件文字满足 WCAG AA 对比度目标；低对比只用于非文字环境装饰。
- 所有可操作控件提供键盘焦点样式；色彩不是唯一状态提示。
- `prefers-reduced-motion: reduce` 时关闭非必要过渡；常规动效短、轻、不循环。
- 玻璃模糊失效时仍保证控件文字、边缘和层级可辨。

## 验收方式（实施后执行；当前不运行应用改版）

1. **范围检查**：变更只涉及三页的模板/CSS 呈现；无路由、API、数据模型、请求参数或业务逻辑差异。
2. **视觉检查**：在桌面（约 `1280px`）和窄屏（约 `390px`）检查三页；搜索页独有极淡环境氛围，图库/缓存无场景图；浅蓝白风格一致，作品网格突出。
3. **控件检查**：筛选/排序/搜索类型/输入框/按钮为约 `8px` 圆角矩形，约 `36px` 可见高度，实际 hit area ≥ `44px`；不会被误做成胶囊。
4. **功能烟测**：搜索模式、筛选、排序、分页、下载入口、图库收藏/批量操作、缓存浏览/过滤/刷新仍按现有行为工作；点击卡片仍按当前页已有行为导航。
5. **可访问性检查**：键盘焦点、颜色对比、减少动态效果和玻璃效果回退均符合本规格。
6. **回归测试**：实施后运行相关页面/API 测试与完整离线测试；本规格/ mockup 阶段不改应用文件，也不运行应用回归。
